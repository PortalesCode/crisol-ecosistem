# Mi Proyecto - Configuración Mínima de Crisol-Eco

## Resumen

Este proyecto está configurado con **Crisol-Eco**, un ecosistema de desarrollo autónomo que proporciona:

- **North Agent** - Planificación y dirección
- **Executor Agent** - Implementación técnica
- **Auditor Agent** - Revisión de calidad

## Estructura

```
mi-proyecto/
├── .opencode/              # Crisol-Eco ecosystem
│   ├── AGENTS.md          # Documentación completa del ecosistema
│   ├── context/            # Archivos de contexto del proyecto (pendientes)
│   ├── .git/              # Control de versiones
│   ├── gitignore-add      # Template para .gitignore

│       ├── domains/       # Dominios de conocimiento
│       └── Memoria/       # Sistema de memoria persistente

```

## Próximos Pasos

### 1. Configurar el Proyecto

Completa los archivos de contexto en la raíz del proyecto:

**PROJECT.md** - Propósito y objetivos del proyecto
```markdown
# Mi Proyecto

## Propósito
[Describe qué construyes y por qué]

## Objetivos
- [ ] Objetivo 1
- [ ] Objetivo 2
- [ ] Objetivo 3
```

**CONVENTIONS.md** - Reglas y estándares
```markdown
# Convenciones de Código

## Estilo
- [ ] Lenguaje específico
- [ ] Formato de código
- [ ] Nombres de variables

## Git
- [ ] Convenciones de commit
- [ ] Estrategia de branch
- [ ] Proceso de PR
```

**ARCHITECTURE.md** - Arquitectura técnica
```markdown
# Arquitectura

## Componentes
- [ ] Componente 1
- [ ] Componente 2
- [ ] Componente 3

## Patrones
- [ ] Patrón 1
- [ ] Patrón 2
```

**STATUS.md** - Estado actual
```markdown
# Estado

## Progreso
- [ ] Tarea 1
- [ ] Tarea 2
- [ ] Tarea 3

## Próximos Pasos
- [ ] Próximo paso 1
- [ ] Próximo paso 2
```

### 2. Iniciar el Desarrollo Autónomo

Una vez que los archivos de contexto estén completos:

```bash
# El ecosistema detectará automáticamente tu proyecto
# North Agent te ayudará a planificar
# Executor Agent implementará código

```

### 3. Usar el Ecosistema

**Flujos de Trabajo Típicos:**

1. **Planificación** - North Agent desglosa tareas
2. **Implementación** - Executor Agent escribe código
3. **Revisión** - Auditor Agent valida calidad
4. **Iteración** - Repetir según sea necesario

## Preguntas Frecuentes

### ¿Qué pasa si no tengo un proyecto aún?
**Crea uno primero** - Crisol-Eco necesita un proyecto para funcionar. Puedes crear un proyecto simple y completarlo gradualmente.

### ¿Qué pasa si no sé por dónde empezar?
**Empieza con PROJECT.md** - Solo escribe un párrafo sobre qué quieres construir. Puedes refinarlo después.

### ¿Puedo usar Crisol-Eco sin completar todos los contextos?
**Sí, pero limitado** - El ecosistema funciona con contextos parciales, pero es mejor completarlos para mejor dirección.

### ¿Cómo sé cuándo estoy listo para el ecosistema?
**Cuando tengas:**
- Propósito claro (PROJECT.md)
- Reglas básicas (CONVENTIONS.md)
- Arquitectura inicial (ARCHITECTURE.md)
- Estado actual (STATUS.md)
